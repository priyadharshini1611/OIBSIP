# House Price Prediction with Linear Regression

## Objective
To predict house prices using a Linear Regression machine learning model.

## Dataset
Kaggle House Prices dataset (`train.csv`).

## Features Used
- OverallQual
- GrLivArea
- GarageCars
- TotalBsmtSF
- FullBath

## Tools Used
Python, Pandas, NumPy, Matplotlib, Scikit-learn, Google Colab.

## Model Evaluation
- MAE: 25453.16
- RMSE: 40051.20
- R² Score: 0.7909

## Result
The Linear Regression model was trained and evaluated using a train-test split. Actual and predicted house prices were compared using a graph.
