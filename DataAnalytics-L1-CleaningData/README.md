# OIBSIP Data Analytics - Task 3: Cleaning Data

## Objective
To clean a messy dataset and prepare it for analysis using Python, Pandas, and NumPy.

## Dataset
Titanic Dataset (`train.csv`)

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab

## Tasks Completed
1. Loaded the Titanic dataset.
2. Generated a data quality report.
3. Handled missing values in Age and Embarked columns using median and mode.
4. Removed the Cabin column because it contained many missing values.
5. Checked for and removed duplicate rows.
6. Standardised Sex and Embarked values.
7. Detected outliers in Age and Fare using the IQR method.
8. Corrected data types.
9. Created a before-and-after cleaning summary.
10. Saved the cleaned dataset as `cleaned_dataset.csv`.

## Results
- Original dataset: 891 rows and 12 columns.
- Cleaned dataset: 891 rows and 11 columns.
- Missing values after cleaning: 0.
- Duplicate rows after cleaning: 0.

## Output
The cleaned dataset was saved as `cleaned_dataset.csv`.

## Conclusion
The Titanic dataset was cleaned and prepared for further analysis using Python.
