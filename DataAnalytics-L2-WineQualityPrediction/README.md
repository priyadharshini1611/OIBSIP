# Wine Quality Prediction

## Objective
To predict wine quality based on its chemical properties using machine learning classification models.

## Dataset
Wine Quality Red Wine dataset from the UCI Machine Learning Repository.

- Total records: 1599
- Input features: 11 chemical properties
- Target column: quality

## Models Used
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Conclusion
Three classification models were trained and evaluated to predict wine quality. Their performance was compared to identify the best-performing model on the test dataset.
